# ADLC — Agentic Development Lifecycle

**ADLC** là hệ thống multi-agent hỗ trợ phát triển phần mềm theo nguyên tắc:
**agent làm phần nặng, con người đứng ở 3 điểm duyệt** (① đặc tả — ② mã nguồn — ③ sản phẩm).
Hệ thống gồm 4 tầng:

| Tầng | Vai trò |
|---|---|
| **1 · Interface** | Nguồn công việc: IDE, Git, CI/CD, chatbot, Jira/ticketing |
| **2 · Workflow** | Control plane: state machine vòng đời task, factory registry, các cổng duyệt |
| **3 · Harness** | Agent core, công cụ & tri thức: task loop, memory, kiểm thử, vault |
| **4 · Sandbox** | Môi trường thực thi cô lập: broker, VFS service, OpenSandbox lifecycle server |

:::note Lưu ý về bảo mật tài liệu
Tài liệu này mô tả kiến trúc và cách vận hành ở mức thiết kế. **Không đưa vào docs**: token,
mật khẩu, URL nội bộ thật, đường dẫn máy thật, hay nội dung chi tiết của factory repo
(workflow/agent cụ thể) — đó là tài sản riêng của từng nhóm. Secret chỉ được nhắc qua **tên biến
môi trường** hoặc **tên ref** trong vault.
:::

## Quy ước của bộ docs

1. **Một chỗ duy nhất** — một khái niệm chỉ được viết chi tiết ở 1 mục; các mục khác link sang.
2. **Số mục = số prefix** — sidebar tự sinh từ cấu trúc thư mục, không cần sửa `sidebars.ts`.
3. Mỗi trang HDSD kết thúc bằng **"Kết quả đúng phải thấy"**.
4. Mỗi trang kiến trúc mở bằng **1 sơ đồ** (tái dùng hình từ các slide trong `static/img/`).
