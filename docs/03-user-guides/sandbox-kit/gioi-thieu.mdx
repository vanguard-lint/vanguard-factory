Sandbox Kit là tầng thực thi cô lập — Broker · VFS · Provisioner · Warm pool. Kiến trúc:
[Tầng 4 · Sandbox](/docs/architecture/tang-4-sandbox).

## Khái niệm chính

| Khái niệm | Ý nghĩa |
|---|---|
| **Phiên (session)** | Môi trường bật khi cần, giới hạn tài nguyên & phạm vi riêng |
| **VFS** | Tệp dự án lưu riêng, sống độc lập với phiên — phiên tắt, tệp vẫn còn |
| **Broker** | Cổng API duy nhất: cấp phiên, đồng bộ tệp, chạy lệnh |
| **Review** | Giao diện xem Agent đã đổi gì trước khi nhận thay đổi |
| **Plugin vai-sandbox** | Bộ công cụ để agent gọi sandbox đúng lúc, đúng việc |

## Luồng sử dụng điển hình

1. **Chuẩn bị** — lưu script/cấu hình trong workspace; chọn môi trường phù hợp bài test.
2. **Yêu cầu chạy** — broker cấp phiên khi cần; đồng bộ tệp thay đổi rồi thực thi trong môi trường
   riêng.
3. **Lưu để dùng lại** — kết quả về hệ thống gọi; script giữ trong workspace để chạy hồi quy.

## Review diff & merge

- Thay đổi của agent hiển thị qua **giao diện review** trước khi nhận — khớp nguyên tắc
  [Git contract](/docs/architecture/giao-tiep#contract-git): người duyệt merge.
- Dòng git: clone → VFS (không giữ `.git`) → commit trong vùng tạm → push lên nhánh agent.
