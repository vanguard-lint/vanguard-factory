Phần này hướng dẫn **vận hành** Sandbox Kit: cấp phiên, làm việc với tệp, gộp thay đổi.
Giới thiệu hệ thống và kiến trúc xem tại [Tầng 4 · Sandbox](/docs/architecture/tang-4-sandbox/tong-quan).

## Luồng sử dụng điển hình

1. **Chuẩn bị** — clone repo vào workspace hoặc nạp tệp qua API VFS.
2. **Cấp phiên & chạy lệnh** — broker cấp sandbox, thực thi lệnh có timeout.
3. **Gộp thay đổi** — commit/push lên nhánh `agent-*`; người duyệt merge ở Gitea.

## Các trang hướng dẫn

   thu hồi

   cpu/memory/ttl, gia hạn, lệnh bị chặn
