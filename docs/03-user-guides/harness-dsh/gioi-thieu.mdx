# Harness (DSH) — hướng dẫn sử dụng

Harness (DSH) là nơi agent thực thi task: nhận brief, dùng model/công cụ, làm việc trong
workspace và trả report. Với công việc theo workflow, điểm bắt đầu là **dashboard Workloop**.
Bạn chọn workflow, theo dõi ở **Runs** và xử lý các điểm cần người quyết định ở **Duyệt**.

Giao diện DSH dùng để quản trị model, plugin, secret và kiểm tra chi tiết phiên. Kiến trúc:
[Tầng 3 · Harness](/docs/architecture/tang-3-harness/tong-quan-harness).

:::note[Bản hướng dẫn chờ nghiệm thu môi trường]

Nội dung được đối chiếu gateway Workloop và mã plugin hiện có. Địa chỉ, phiên bản triển khai
và quyền truy cập cần được quản trị viên xác nhận. Hướng dẫn không đồng nghĩa với việc đã chạy
một workflow TestForge mới trên môi trường của bạn.

:::

## Khái niệm chính

| Khái niệm | Ý nghĩa |
|---|---|
| **Workloop job** | Một lần chạy DAG, có các node và lịch sử sự kiện riêng |
| **Session** | Phiên agent của một task/attempt; dùng session ID để tra cứu trong DSH |
| **Workspace** | Không gian tệp trên host/container Harness; không mặc nhiên là thư mục trên máy người dùng |
| **TaskLoop contract** | Hợp đồng tiến độ nhiệm vụ; gateway dùng để xác định node đã kết thúc |
| **Plugin** | Gói đăng ký tool; có thể gọi backend bên ngoài như TestForge broker |
| **Vault** | Nơi runtime lấy secret theo tên ref |
| **HITL** | Điểm cần con người quyết định, thường xử lý qua card duyệt Workloop |

## Kết quả đúng phải thấy

1. Workloop thấy đúng workflow và SHA sau sync.
2. Workflow một node chạy được qua gateway DSH; model/provider khớp cấu hình.
3. Report chứa session ID và trạng thái contract; tệp đầu ra thực sự tồn tại.
4. Với TestForge, report còn có **TestForge job ID** và bằng chứng của đúng SUT/suite.

Health đạt xác nhận một dịch vụ có phản hồi. Để kết luận công việc đạt, cần đọc report,
kiểm tra đầu ra và hoàn thành review theo workflow.

## Điểm vào giao diện

| Ở đâu | Khi nào dùng |
|---|---|
| Workloop → **Factory / Workloop** | Kiểm tra workflow đã sync và cấu trúc DAG |
| Workloop → **Runs** | Xem node, report, attempt và session ID |
| Workloop → **Duyệt** | Đọc ngữ cảnh rồi duyệt, yêu cầu sửa hoặc từ chối |
| DSH → phiên agent tương ứng | Đọc tool call, lỗi model hoặc nội dung phiên để chẩn đoán |
| DSH → **Plugins / Settings → Secrets** | Quản trị plugin và credential |

Tên mục quản trị DSH có thể khác theo bản triển khai; dùng URL do admin cấp, giữ nguyên token
trong công cụ quản lý secret. Không dán token vào brief, ảnh chụp hoặc link chia sẻ.
