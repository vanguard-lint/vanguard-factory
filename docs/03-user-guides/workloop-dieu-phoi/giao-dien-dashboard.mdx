# Giao diện dashboard

## Mục đích

Dashboard là giao diện quản trị tập trung của tầng Workflow: theo dõi sức khỏe hệ thống, xem cấu
trúc DAG, đọc report từng node và xử lý **card duyệt HITL**. Các tab chính:

| Tab | Dùng để |
|---|---|
| **Dashboard** | Tổng quan hệ thống — health, số run, xu hướng |
| **Workloop** | Canvas workflow — xem cấu trúc DAG, vị trí node (layout) |
| **Runs** | Danh sách run, chi tiết job, timeline (Gantt), report từng node |
| **Duyệt** | **Card duyệt HITL** — đọc brief/diff/bằng chứng, chấp nhận/từ chối kèm lý do |
| **Factory** | Workflow đã đăng ký (sau sync), cấu hình tenant |
| **Agents** | Persona agent theo role |
| **Webhook** | Quản lý webhook nguồn ngoài |
| **Automation** | Quy tắc tự động hóa (phê duyệt tự động theo cấu hình) |
| **Integration** | Tích hợp ngoài (ví dụ Confluence) |
| **Secret** | Quản lý ref secret (không hiển thị giá trị) |

## Luồng duyệt HITL trong tab Duyệt

1. Node `need_review: human` tới lượt → run tạm dừng, tạo work request duyệt.
2. Card hiện brief + sản phẩm + bằng chứng kèm theo.
3. Người duyệt chọn chấp nhận/từ chối **kèm lý do**.
4. Run tiếp tục; quyết định được ghi vào log trung lập.

## Theo dõi task Harness và TestForge

Với workflow có node kiểm thử, dùng **Runs → job → report của node QA** để đọc kết quả. Report
cần có session ID của Harness, TestForge job ID, target/suite đã dùng và đường dẫn bằng chứng.
Mở phiên DSH tương ứng khi cần kiểm tra tool call; duyệt phạm vi và kết quả tại tab **Duyệt**
theo các gate trong spec.

Đây là quy trình qua các tab hiện có. Workflow mẫu và yêu cầu cấu hình nằm tại
[Harness từ Workloop](/docs/user-guides/harness-dsh/van-hanh-workloop) và
[Tích hợp TestForge](/docs/user-guides/testforge/tich-hop-workloop).

## Kết quả đúng phải thấy

Mở tab **Runs** sau một run: mọi node có trạng thái terminal; run có gate chờ duyệt xuất hiện ở
tab **Duyệt** với đầy đủ ngữ cảnh để ra quyết định.

## Lỗi thường gặp

| Hiện tượng | Xử lý |
|---|---|
| Tab **Factory** trống | backend chưa sync factory repo — gọi `POST /api/v1/flows/sync` ([Cài đặt](/docs/user-guides/workloop-dieu-phoi/cai-dat)) |
| Card duyệt biến mất | quá TTL 48h không ai trả lời bị swept thành từ chối — chạy lại với `resume` ([Xử cố](/docs/user-guides/workloop-dieu-phoi/xu-co)) |
| Trả lời card báo 409 | gateway của run đã kết thúc — chạy lại với `resume` ([Xử cố](/docs/user-guides/workloop-dieu-phoi/xu-co)) |
