# Tham chiếu

## Cấu trúc thư mục

```text
testforge-ai/
├─ testforge_broker.py          # HTTP Broker, job, health, metrics, auth
├─ cognee_adapter.py            # Adapter /v1 cho Cognee
├─ Dockerfile
├─ docker-compose.yml
├─ docker/Dockerfile.broker-upgrade
├─ requirements.txt
├─ package.json / package-lock.json
├─ playwright.config.ts
├─ schemas/                     # hợp đồng đầu vào, kết quả, artifact
├─ scripts/                     # CLI: explore, replay, orchestrate, perf, staging, impact
├─ src/
│  ├─ agent1/                   # normalizer, explorer, designer, generator, healer, staging
│  ├─ agent2/                   # workload, k6 runner, evaluator
│  ├─ agent3/                   # optimizer / recommendation
│  ├─ impact/                   # graph, selector, engine
│  ├─ execution/                # backend, sandbox runner
│  └─ observability/            # log JSON, request context
├─ opt/
│  ├─ perf/                     # requirement, users.json
│  ├─ staging/                  # profile, suite, generated
│  ├─ impact/                   # config, suite, profile, example
│  ├─ gherkin/, testspec/
│  └─ sut-tnqd/
├─ plugin/testforge-ai/         # tool cho agent harness
├─ artifacts/
│  ├─ inputs/                   # Standard Test Input đã duyệt
│  ├─ library/                  # thư viện dùng lại
│  ├─ automation/exploration/   # EXPLORE-*
│  ├─ automation/staging/       # STAGING-*
│  ├─ impact/                   # IMPACT-*
│  ├─ broker/                   # log JOB-*.log
│  └─ perf/                     # PRUN-*, REC-*
├─ tests/
└─ docs/
```

## Artifact theo loại run

| Run | Thư mục | Nội dung chính |
|---|---|---|
| `EXPLORE` | `artifacts/automation/exploration/EXPLORE-<id>/` | `session_summary.json`, `trace.jsonl`, ảnh từng step, `input.feature`, `video/`, `owned.json`, `synthesis/` |
| `STAGING` | `artifacts/automation/staging/STAGING-<id>/` | summary, JUnit, evidence; khi có impact: `impact_plan.json`, `selected_suite.json`, `impact_result.json` |
| `PRUN` | `artifacts/perf/PRUN-<id>/` | requirement, script k6, NDJSON, `performance_result.json` |
| `REC` | `artifacts/perf/REC-<id>/` | `issue_summary`, `evidence`, `likely_causes`, `action`, `validation_plan` |
| `IMPACT` | `artifacts/impact/IMPACT-<hash>/` | `impact_plan.json` |
| `JOB` | `artifacts/broker/JOB-<id>.log` | Log subprocess |

## Checklist bàn giao môi trường

Ghi lại đầy đủ:

- [ ] Image digest / commit / `BUILD_REVISION`
- [ ] Interpreter và danh sách dependency thực tế
- [ ] URL Broker / UI / API / Adapter
- [ ] Tên dataset Cognee + phiên bản tài liệu
- [ ] Nguồn cấp bí mật (không ghi giá trị)
- [ ] Thư viện testcase đã duyệt (`artifacts/inputs`, `artifacts/library`)
- [ ] Volume và chính sách retention
- [ ] Tài khoản và vai trò cho từng môi trường
- [ ] Kết quả health → recall → explore → replay → perf
- [ ] Đường dẫn evidence mẫu

Bàn giao **riêng** cấu hình có bí mật qua kênh được cấp quyền.
