# Cấu hình hệ thống

:::warning[Đọc cấu hình khi khởi động]
Broker đọc phần lớn biến môi trường **lúc import module**. Sửa biến rồi chạy lại lệnh trong cùng tiến trình sẽ **không** có tác dụng — phải khởi động lại Broker.
:::

## Broker và kết nối

| Biến | Giá trị và tác dụng |
|---|---|
| `TESTFORGE_BROKER_TOKEN` | Token client gửi qua `Authorization: Bearer`. Khi **rỗng**, hàm xác thực cho request đi tiếp — chỉ dùng trong mạng tin cậy |
| `TESTFORGE_BROKER_URL` | Địa chỉ phía client/plugin/composer gọi Broker; **không** đổi cổng listen của server |
| `TESTFORGE_PYTHON` | Interpreter cho subprocess. Mặc định `sys.executable`; phải có đủ dependencies |
| `TESTFORGE_JOB_TIMEOUT` | Mặc định 600 giây. `job_timeout_seconds` trong request được kiểm trong khoảng 30–1200 |
| `TESTFORGE_ALLOWED_ORIGINS` | Danh sách Origin cách nhau dấu phẩy. Middleware chỉ kiểm khi request có `Origin`; **không** phải phân quyền người dùng hay firewall |
| `AGENT_MEMORY_API_URL` | Base URL Adapter, có hậu tố `/v1`. Mặc định `http://127.0.0.1:8000/v1`; khi tách riêng Adapter, trỏ tới `http://<adapter-host>:<adapter-port>/v1` |
| `AGENT_MEMORY_API_KEY` | Bearer token gọi Adapter nếu được bật. **Khác** token Broker |
| `TESTFORGE_EVIDENCE_BASE_URL` | Base URL dựng link ảnh/video/HTML trong báo cáo; phải là địa chỉ client thực sự truy cập được |
| `LOG_LEVEL`, `LOG_JSON` | Mặc định `INFO`, JSON `true` |
| `TESTFORGE_SUT_BASE_URL`, `TESTFORGE_SUT_API_URL` | Giá trị dự phòng cho đường `command/execute`; endpoint explore trực tiếp vẫn cần gửi `base_url`, `api_url` |
| `TESTFORGE_SUT_EMAIL`, `TESTFORGE_SUT_ACTOR` | Danh tính dự phòng cho `command/execute` |
| `TESTFORGE_SUT_PASSWORD_ENV` | **Tên** biến mật khẩu dự phòng; mặc định `SUT_ADMIN_PASSWORD` |

### Biến runtime của bản có Sandbox và Impact

| Biến | Giá trị và tác dụng |
|---|---|
| `TESTFORGE_EXECUTION_BACKEND` | `local` (mặc định) hoặc `sandbox-kit`. Chọn backend thực thi; giá trị được báo trong `health` |
| `TESTFORGE_SANDBOX_IMAGE` | Tên image sandbox dùng khi chạy qua Sandbox-Kit; hiển thị trong `health` |
| `TESTFORGE_SOURCE_REVISION` | Revision của bản build; **bắt buộc** khi `docker compose` vì dùng làm tag image |

:::note[`PROJECT_ROOT`]
`PROJECT_ROOT` lấy từ vị trí file `testforge_broker.py`. Biến `TESTFORGE_PROJECT_ROOT` xuất hiện trong mô tả đầu file nhưng **không** được dùng để đổi thư mục gốc. Muốn đổi nơi chạy, đặt bản mã/volume ở vị trí phù hợp rồi kiểm tra `project_root` trong `health`.
:::

## Tài khoản SUT

| Nhóm | Cách thiết lập và kiểm tra |
|---|---|
| Mật khẩu SUT | Tên biến tự chọn, ví dụ `SUT_ADMIN_PASSWORD`. Cấp trong môi trường tiến trình chạy script/Broker, rồi gửi `password_env` cùng tên |
| Header bổ sung | `TESTFORGE_BROWSER_EXTRA_HEADERS` — chuỗi JSON header cho browser context khi SUT cần identity do gateway cấp. Chỉ dùng với tài khoản/phạm vi test đã duyệt |
| Đăng nhập | Login thử `POST {api_url}/auth/login`, sau đó fallback sang form UI |

```powershell
$secret = Read-Host 'Mat khau tai khoan test' -AsSecureString
$env:SUT_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new(
  '', $secret).Password
# Chi cap header khi SUT thuc su yeu cau:
# $env:TESTFORGE_BROWSER_EXTRA_HEADERS = '<JSON da duyet>'
```

:::warning[Giá trị đặc biệt `ui`]
Giá trị mật khẩu `ui` kích hoạt lối **đăng nhập nhanh** của một số hệ thống mẫu. Đây là tính năng phục vụ môi trường phát triển, **không** phải bộ thích nghi SSO tổng quát.
:::

## LLM

| Biến | Giá trị và tác dụng |
|---|---|
| `OPENCODE_BASE_URL` | Base URL OpenAI-compatible; client nối thêm `/chat/completions` |
| `OPENCODE_API_KEY` | Khóa provider. Không đưa vào testcase hoặc báo cáo |
| `TESTFORGE_LLM_MODEL` | Tên model theo provider. Kiểm tra structured output bằng một lần compose thử |
| `OPENCODE_TIMEOUT_SECONDS` | Thời gian chờ LLM; client mặc định 120 giây |
| `opencode.json` | Fallback cấu hình LLM cục bộ; **không** được COPY vào image |

## File `opt/broker.env`

Docker Compose đọc file này qua `env_file`. Python chạy trực tiếp **không** tự nạp file.

```bash
TESTFORGE_BROKER_TOKEN=REPLACE_WITH_BROKER_TOKEN
AGENT_MEMORY_API_URL=http://<adapter-host>:<adapter-port>/v1
AGENT_MEMORY_API_KEY=REPLACE_WITH_ADAPTER_TOKEN
TESTFORGE_EVIDENCE_BASE_URL=http://<broker-host>:9099
TESTFORGE_JOB_TIMEOUT=600
TESTFORGE_SOURCE_REVISION=REPLACE_WITH_BUILD_REVISION
SUT_ADMIN_PASSWORD=REPLACE_WITH_TEST_PASSWORD
LOG_LEVEL=INFO
LOG_JSON=true
```

Giới hạn quyền đọc file trên máy chủ.

:::note[Placeholder trong mẫu]
`<adapter-host>`, `<broker-host>` là **chỗ cần điền**, không phải giá trị chạy được. Thay bằng địa chỉ thật từ tài liệu bàn giao môi trường; không commit file chứa giá trị thật lên Git.
:::

Khi sửa `env_file` của container phải **tạo lại container**:

```bash
docker compose up -d broker
```

`docker restart` đơn thuần **giữ nguyên** cấu hình môi trường cũ.

## Nguyên tắc bí mật

- Dùng nguồn bí mật **riêng** cho: token Broker, token Adapter, tài khoản SUT, khóa LLM.
- Kiểm tra cấu hình bằng trạng thái "đã có / chưa có" hoặc request thử; không in giá trị ra terminal hay log chia sẻ.
- Khi gửi sự cố: che secret, `storage.state.json`, dữ liệu tài khoản.
