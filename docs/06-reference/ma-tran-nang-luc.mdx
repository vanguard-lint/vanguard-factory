## Năng lực gắn với mọi pha (X)

| Mã | Năng lực | Benchmark tham chiếu | Cách chấm |
|---|---|---|---|
| X1 | Lập kế hoạch, phân rã tác vụ nhiều bước | SWE-bench, CodeAgentBench, ProjectEval | Thực thi; giả lập người dùng |
| X2 | Dùng công cụ, tương tác môi trường, gỡ lỗi lặp | Spider2-v, MLAgentBench, ML-bench, RedCode | Thực thi |
| X3 | Hiểu ngữ cảnh repo, phụ thuộc chéo file | CoderEval, DevEval, RepoBench, CrossCodeEval | Thực thi; so khớp |
| X4 | Nhận biết tiến hóa của code và yêu cầu | HumanEvo, SWA-Bench, SWEE-Bench | Thực thi |
| X5 | Chất lượng phi chức năng: bền vững, bảo mật, hiệu quả | ReCode, RMCBench, ECCO, EffiBench… | Thực thi; tĩnh |
| X6 | Đa ngôn ngữ, đa phương thức | HumanEval-X, MultiPL-E, Web2Code… | Thực thi; LLM-judge |

## Review (RV) · Vận hành (OP) · Tài liệu (DC)

| Mã | Năng lực | Benchmark | Cách chấm |
|---|---|---|---|
| RV1 | Tìm lỗi, lỗ hổng, vấn đề kiến trúc trong PR | ReviewBench, c-CRAB, CodeLens | LLM-judge; test |
| RV2 | Viết nhận xét làm theo là sửa được code | c-CRAB | Thực thi test |
| RV3 | Phân loại mức nghiêm trọng, cân precision/recall | ReviewBench | LLM-judge |
| RV4 | Đưa kết luận cuối cho PR | CodeLens | Điểm theo kịch bản |
| RV5 | Phán đoán thiết kế, khả năng bảo trì | Senior SWE-Bench | Chưa rõ |
| RV6 | Phân tích tĩnh: API misuse, clone | APIMU4C, BigCloneBench | Tĩnh |
| OP1 | Thao tác terminal, sysadmin, build | Terminal-Bench | Script kiểm chứng |
| OP2 | Phát hiện, khoanh vùng sự cố | AIOpsLab, ITBench | Môi trường mô phỏng |

| DC1 | Tóm tắt code, sinh comment | CODE-NN, TL-CodeSum | So khớp |
