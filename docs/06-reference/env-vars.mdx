# Env vars Reference

> **Quy tắc:** giá trị token/cred **không bao giờ** ghi vào repo/docs — chỉ đặt trên host hoặc
> vault. Bảng này chỉ liệt kê **tên** + ý nghĩa.

## Backend workloop

| Biến | Ý nghĩa |
|---|---|
| `WORKLOOP_TOKEN` | bearer token bảo vệ API backend |
| `WORKLOOP_DB` | đường dẫn SQLite (jobs, events, chỉ mục) |
| `WORKLOOP_SRC` | thư mục mã nguồn backend |
| `WORKLOOP_DSH_WS` | workspace id trên harness |
| `WORKLOOP_SECRETS` | bật nhóm API secrets |
| `WORKLOOP_IMPROVE` | bật nhóm API cải tiến (scorers/benchmarks) |
| `WORKLOOP_WEBHOOKS` | bật nhóm API webhooks |
| `WORKLOOP_TRACING` | `1` = bật gửi traces tới Phoenix |
| `WL_PORT` | cổng frontend dashboard |

## Factory

| Biến | Ý nghĩa |
|---|---|
| `FACTORY_REPO_URL` | URL factory repo (nguồn sự thật spec + agents) |
| `FACTORY_REPO_BRANCH` | branch sync (mặc định `main`) |
| `FACTORY_PATH` | checkout cục bộ của backend |

## Harness (DSH)

| Biến | Ý nghĩa |
|---|---|
| `DSH_TOKEN` | Token Web UI/SDK DSH; kiểm tra lại sau restart theo deployment |
| `DSH_BASE_URL` | URL DSH mà SDK Python và các helper có hỗ trợ đọc |
| `DSH_TIMEOUT` | Timeout request của SDK Python, mặc định 30 giây |

Gateway DSH tham chiếu lấy URL/workspace từ `harness` trong `factory.yaml`, token qua tên biến
`token_env` (thường là `DSH_TOKEN`). Các biến URL/workspace riêng chỉ có tác dụng khi script
deployment thực sự đọc chúng. Xem [Kết nối Harness](/docs/user-guides/harness-dsh/cai-dat-ket-noi).

## Profile ADLC trên Harness

Đường tích hợp ADLC dùng API và credential riêng. Gateway TaskLoop của Workloop không tự
chuyển sang execution hub khi khai báo các biến này.

| Biến/ref | Nơi sử dụng | Ý nghĩa |
|---|---|---|
| `ADLC_HARNESS_BASE_URL` | Client ADLC | URL gốc execution hub |
| `ADLC_HARNESS_API_TOKEN` | ADLC và hub | Bearer control API, khác `DSH_TOKEN` |
| `ADLC_HARNESS_CALLBACK_URL` | Hub | Callback cố định do deployment cấp |
| `ADLC_HARNESS_CALLBACK_SECRET` | Hub và receiver ADLC | Secret ký/kiểm tra HMAC callback |
| `ADLC_HARNESS_SOURCE_REPO` | Compose Harness | Repo nguồn mount chỉ đọc cho capture Git |
| `ADLC_HARNESS_ITERATION_API_TOKEN` | ADLC và iteration plugin | Bearer riêng cho API chỉ đề xuất file |
| `ADLC_TASK_LOOP_HARNESS_ENABLED` | Backend ADLC | Opt-in adapter native iteration |
| `ADLC_CONTRACT_EXECUTION_ENABLED` | Backend ADLC | Opt-in execution theo contract đã duyệt |
| `ADLC_CONTRACT_RECOVERY_ENABLED` | Backend ADLC | Opt-in profile recovery cùng execution tương ứng |

Flags không thay việc cài plugin, kiểm tra lock và cấu hình profile. Tra
[giao diện Harness](/docs/reference/harness-interfaces) để chọn API và credential.

## TestForge

| Biến/ref | Đặt tại | Ý nghĩa |
|---|---|---|
| `TESTFORGE_BROKER_URL` | Vault DSH hoặc môi trường runtime plugin | URL gốc broker, không kèm `/api/v1` |
| `TESTFORGE_BROKER_TOKEN` | Vault DSH hoặc môi trường runtime plugin | Token API broker, khác token DSH/Workloop |
| `TESTFORGE_TOKEN` | Môi trường runtime plugin | Alias tương thích; ưu tiên tên chuẩn ở trên |
| `AGENT_MEMORY_API_URL` | Broker TestForge có Cognee Adapter | Base URL HTTP `/v1` của Adapter; khác MCP URL của plugin Agent Memory |
| `AGENT_MEMORY_API_KEY` | Broker TestForge có Cognee Adapter | Credential gọi Adapter; khác token broker |
| Tên biến do `password_env` chỉ định | Môi trường broker/runner | Mật khẩu tài khoản SUT; chỉ truyền tên ref vào tool |

Profile staging có thể có cấu hình credential riêng theo runner. Cài plugin không đồng bộ
secret giữa Workloop, DSH và broker. Xem [Kết nối TestForge](/docs/user-guides/testforge/cai-dat-ket-noi).

`AGENT_MEMORY_API_URL` trỏ tới **Cognee Adapter** — cổng chuyển tiếp giữa broker và bộ nhớ tri
thức chung; mã truy cập Adapter không dùng thay mã MCP của plugin Agent Memory
(xem [Memory → TestForge](/docs/user-guides/agent-memory-cognee/tich-hop-testforge)).

Plugin tham chiếu phân giải kết nối theo mỗi lời gọi; broker mô tả trong
[PR #5](https://github.com/vanguard-lint/vanguard-factory/pull/5) đọc phần lớn env lúc khởi động.
Không suy ra thay đổi env broker có hiệu lực chỉ vì đã cập nhật secret phía Harness.
